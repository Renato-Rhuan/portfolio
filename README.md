# 🚀 Renato.Dev — Portfólio Profissional

Meu portfólio pessoal como **Desenvolvedor Full Stack**, desenvolvido para apresentar minhas habilidades, experiências, projetos e tecnologias utilizadas na criação de soluções digitais.

🌐 **Acesse o projeto:** [portfolio-alpha-seven-85.vercel.app](https://portfolio-alpha-seven-85.vercel.app/)

## 📸 Sobre o projeto

O Renato.Dev foi criado com o objetivo de apresentar minha trajetória na programação, demonstrar meus conhecimentos técnicos e reunir meus principais projetos em um único lugar.

O projeto possui uma interface moderna, responsiva e intuitiva, priorizando a experiência do usuário, organização visual e facilidade de navegação.

## ✨ Funcionalidades

- Página inicial com apresentação profissional.
- Seção sobre mim e minha trajetória.
- Apresentação das habilidades e tecnologias.
- Galeria de projetos desenvolvidos.
- Filtros para organização dos projetos por tecnologia.
- Links para projetos publicados e repositórios no GitHub.
- Seção de contato com links para comunicação.
- Download do currículo.
- Layout responsivo para diferentes dispositivos.

Demonstrar minha evolução como desenvolvedor, compartilhar projetos práticos e conectar meu trabalho a novas oportunidades profissionais e projetos freelance.
